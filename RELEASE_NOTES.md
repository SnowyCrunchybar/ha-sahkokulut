# Julkaisutiedote / Release notes

## Versio 1.2.7

### Suomeksi

- Lisättiin vuokra-/nimikkopaneelien arvioitu energiamaksuhyvityssensori.
- Arvioitu hyvitys toimii reaaliaikaisista mittareista ja viiveellä päivittyvistä tilastotiedoista.
- Kiinteä-, pörssi- ja hybridisopimuksen hyvityksen yksikköhinta lasketaan sopimuksen tiedoista.
- Vuokrapaneelin valinta ja tuottoanturin tunnistus parantuivat asetuksissa.
- Paketin versio päivitettiin 1.2.7:ään.

### English

- Added an estimated energy-credit sensor for rented or named solar panels.
- Estimated credit supports real-time sensors and delayed recorder statistics.
- The credit rate is calculated from fixed, spot-price and hybrid contract settings.
- Improved rented-panel selection and generation-sensor discovery in the setup flow.
- Updated the package version to 1.2.7.
